课间课程表 {{VERSION}} · Windows 10/11 x64

请先从托盘退出旧版课间，并关闭旧课程工具。把完整压缩包解压到固定、可写的文件夹，再运行课间课程表-{{VERSION}}.exe。不要直接在压缩包内运行。

发布包已直接包含“课间数据”目录、浏览器扩展及课程工具运行程序。完整解压后，无需先启动课表即可安装扩展。主课表 timetable.json、提醒设置 settings.json 和浏览器配置在首次运行后生成。

所有课间自身的数据都在 EXE 旁的“课间数据”文件夹中：课表快照、提醒设置、浏览器配置、签到窗口配置、课程工具、扩展、HAR 记录、导出默认目录和临时运行文件。正常运行不再把数据写到 AppData；目录不可写时会报错，不会改用其他位置。

公开版不自动读取或迁移 AppData 中的旧版课表。已有同目录数据仍正常保留；需要恢复备份时，请在程序中手动导入 JSON。

移动、备份或换位置时，请带上 EXE 与整个“课间数据”文件夹，不要只复制 EXE。移动之后，浏览器中加载的扩展路径会失效，请按下方步骤重新加载。本包首次解压不含个人登录记录；分享程序时请使用干净的发布包，不要分享使用后的数据目录。

课程工具统一入口：左侧“课程工具”→“打开课程工具”。同一个工具窗口中可签到，也可点击“提交实验报告…”处理文件型作业或报告。有 classid 的课程卡片可点击“签到与作业”带入课程，读取本人登录后按本人课程列表核对。

功能说明：用于尝试修改签到和作业提交的记录 IP，效果不稳定。推荐机房 IP 段：10.4.211.xxx、10.4.217.xxx、10.4.209.xxx。xxx 是占位符，需替换为实际末段数字，填写完整有效 IP。设置只修改请求头，不改变真实网络出口。重交无法通过当前设置改变平台记录 IP，仍使用平台提供的正常表单。

首次安装浏览器扩展：
1. 打开“课间数据/course-tools/browser-extension”文件夹；也可在课表的课程工具页点击“浏览器扩展文件夹”。
2. 在日常登录学校的 Edge 地址栏输入 edge://extensions；Chrome 使用 chrome://extensions。
3. 打开“开发人员模式／开发者模式”，选择“加载解压缩的扩展／加载已解压的扩展程序”。
4. 选择刚才打开的整个文件夹，其中应含 manifest.json；不要选择单个文件。
5. 确认“课程主页 HAR 桥接”已启用，在同一个浏览器登录学校 EOL，保持学校标签打开。
6. 回到工具点击“读取本机浏览器登录”。浏览器不一致时，复制工具的连接链接到已登录且装好扩展的浏览器中。
迁移或移动文件夹后，请移除失效的旧扩展项目，再从当前位置重新加载。

工具和 Python/Tk 运行组件已经内置，无需另装 Python。打开工具不发送签到或上传请求；账号、课程、IP 与预览核对后需手动发送一次，不自动重试。账号和 Cookie 不进入课表 JSON；主动读取的 HAR 自身含有登录凭据，请只在本机保管。详细功能见“课程工具使用说明.md”。

公开版首次启动为空课表：0 门课程、0 学分，不内置个人课程或 classid 参照。请先设置学期和作息，再添加课程或导入本人 JSON。

导入／导出：在“导入课表”获取格式说明和 AI 提示词，结合本人课表生成 JSON，校验预览后确认替换。已有课间 JSON 可直接导入；JSON 是数据文件，无需双击打开。导出默认位置为“课间数据/exports”，也可自行选择其他备份位置。

提醒：左侧“桌面提醒”中开启开关；课表修改后自动同步。开启提醒后关闭窗口会收起到托盘，右键托盘可退出。

二维码预测：按 classid 和当前时间离线生成；上传图片和原码链接导入也保留。打开签到网页时才联网，首次请求前设置 MicroMessenger UA，平台仍可能要求本人登录或微信授权。

系统仍需 Microsoft Edge WebView2 Runtime，不需要 Node.js 或手动启动网页服务。缺少 Runtime 时可从微软官网安装：https://developer.microsoft.com/microsoft-edge/webview2/

本发布包适用于 Windows 电脑版。第三方许可随发布包提供。
