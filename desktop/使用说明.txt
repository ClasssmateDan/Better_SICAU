Better SICAU 桌面版

课间课程表 {{VERSION}} · Windows 10/11 x64

请先从托盘退出旧版课间，把完整压缩包解压到固定、可写的文件夹，再运行课间课程表-{{VERSION}}.exe。不要直接在压缩包内运行。

发布包包含程序、使用说明、课表导入格式与示例、第三方许可及校验值。主课表 timetable.json、设置 settings.json 和浏览器配置在首次启动后生成。

所有课间自身的数据都在 EXE 旁的“课间数据”文件夹中：课表快照、提醒设置、浏览器配置、签到窗口配置、导出默认目录和临时运行文件。正常运行不再把数据写到 AppData；目录不可写时会报错，不会改用其他位置。

公开版不自动读取或迁移 AppData 中的旧版课表。已有同目录数据仍正常保留；需要恢复备份时，请在程序中手动导入 JSON。

移动、备份或换位置时，请带上 EXE 与整个“课间数据”文件夹，不要只复制 EXE。本包首次解压不含个人登录记录；分享程序时请使用干净的发布包，不要分享使用后的数据目录。

公开版首次启动为空课表：0 门课程、0 学分，不内置个人课程或 classid 参照。请先设置学期和作息，再添加课程或导入本人 JSON。

导入／导出：在“导入课表”获取格式说明和 AI 提示词，结合本人课表生成 JSON，校验预览后确认替换。已有课间 JSON 可直接导入；JSON 是数据文件，无需双击打开。导出默认位置为“课间数据/exports”，也可自行选择其他备份位置。

提醒：左侧“提醒设置”中开启开关；课表与备忘录修改后自动同步。关闭主窗口始终静默收起到托盘，双击托盘图标恢复，右键“退出课间”结束程序，与提醒开关无关。

二维码预测：按 classid 和当前时间离线生成；上传图片和原码链接导入也保留。打开签到网页时才联网，首次请求前设置 MicroMessenger UA，平台仍可能要求本人登录或微信授权。

系统仍需 Microsoft Edge WebView2 Runtime，不需要 Node.js 或手动启动网页服务。缺少 Runtime 时可从微软官网安装：https://developer.microsoft.com/microsoft-edge/webview2/

本发布包适用于 Windows 电脑版。第三方许可随发布包提供。

课程可设置自定义“签到方式”，默认为教务系统。其他方式点击“跳转签到页”时需确认是否继续；旧课表缺少字段时采用默认方式，导入导出会保留该设置。

日历备忘：选择日期后添加或编辑备忘录，填写具体时间并勾选提醒。需在“提醒设置”开启课程与备忘录提醒，并保持程序或托盘运行。日期详情列出当天课程，可标记或撤销签到；标记仅为本地记录，月历以课程对应颜色的实心圆显示签到记录。修改或删除课程后保留历史记录。
日历与课表统一保存在 timetable.json，并随 JSON 导入导出。导入为整体替换；旧文件不含日历字段时将清空当前备忘录与签到记录，请先导出备份。

课表缩放：我的课表根据窗口可用宽高调整行列与字体，缩小或放大窗口时显示完整一周。

版本信息：左下角显示当前桌面版版本号。日历中内置 2026 年官方假期与调休、2027 年节日日期；假期首日或调休上班日等在北京时间 09:00 提醒，需开启系统提醒。2027 年调休安排待更新，课程排课不会自动变动。
