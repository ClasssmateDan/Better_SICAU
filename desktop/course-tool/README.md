# 电脑版课间 · 课程工具

课程工具仅适用于 Windows 版课表。完整发布包已直接附带 `课间数据/course-tools/browser-extension` 扩展文件夹，以及 `课间数据/runtime/1.7.4/course-tools/KeJianCourseTools.exe` 工具运行程序。扩展在解压后即可安装。主课表 `timetable.json`、设置 `settings.json` 和浏览器配置在首次启动后生成；发布包不附带使用后的个人数据。Windows EXE 同时内置这些资源，无需另装 Python，也不依赖原项目文件夹。课间自身的课表、工具、扩展、记录、浏览器配置和临时运行文件统一位于 EXE 旁的“课间数据”目录，不再写入 AppData。

在课表左侧打开“课程工具”，或在有 classid 的课程卡片点击“签到与作业”。课表只传入课程定位信息；工具用本次读取的本人账号与课程列表核对 classid，不将未匹配的课表课程补入账号列表。没有 classid 的课程可直接在工具读取的本人课程列表中选择。

1. 在日常浏览器登录四川农业大学 EOL，保持学校标签打开。首次使用点击“浏览器扩展文件夹”，在 Edge / Chrome 扩展管理中加载该文件夹；如果已配置原课程工具的“课程主页 HAR 桥接”扩展，可继续使用。
2. 统一点击“打开课程工具”。同一个独立窗口提供签到和“提交实验报告…”两项功能；重复打开会回到原窗口并更新课程定位。打开窗口不会读取学校或提交数据。
3. 在工具中点击“读取本机浏览器登录”，主动读取一次本人主页。也可手动导入本人 HAR，再粘贴 Cookie / cURL。登录、课程和 Cookie 沿用上游工具的核对方式。
4. 签到时填写请求头 IP、检查账号、课程与请求预览，然后手动点击“发送一次签到请求”。不会批量发送、轮询或自动重试。
5. 作业窗口支持文件型作业／实验报告。读取任务与当前上传表单，选择非空文件，核对预览后手动上传一次。在线文字、代码等其他任务请在学校网页完成。只有手动点击上传才会读取文件正文并发送 POST。

功能用于尝试修改签到和作业提交的记录 IP，效果不稳定。推荐机房 IP 段：`10.4.211.xxx`、`10.4.217.xxx`、`10.4.209.xxx`；`xxx` 是占位符，使用时需替换为实际末段数字，填写完整有效 IP。设置同时写入 X-Forwarded-For 和 X-Real-IP，不改变真实网络出口。当前请求头设置无法更改报告重交时的平台记录 IP。重交使用平台提供的入口和原表单的重交状态，不能覆盖 isresubmit 字段。

课表与工具之间不传账号、学号、Cookie、报告文件或请求内容，这些也不会进入课表导出文件。工具中的 Cookie 保存在进程内存；主动获取的 HAR 本身含有登录凭据，保存于 `程序目录/课间数据/course-tools/records`，请仅在本机保管。原项目中另一个独立课程工具的记录不会自动导入或复制。

工具仅在点击读取登录时监听原有的本机端口 18763；成功、取消后本次凭据失效，关闭工具会停止监听。已运行其他版本时请先关闭其窗口。课表自身仍为离线静态内容，不启动网页服务。

独立工具窗口关闭后会清空内存中的账号与 Cookie；课表和上下课提醒继续运行。关闭课表也不会中断已经打开的作业窗口。需要切换已有作业窗口的课程时，先完成当前操作并关闭该作业窗口，再从课表选择下一门课。

## 浏览器扩展安装指导

1. 解压完整发布包，打开 `课间数据/course-tools/browser-extension` 文件夹。也可在课表的“课程工具”页面点击“浏览器扩展文件夹”，查看安装步骤并打开同一目录。
2. 在日常登录学校的浏览器地址栏打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）。
3. 打开“开发人员模式／开发者模式”，点击“加载解压缩的扩展／加载已解压的扩展程序”。
4. 选择刚才打开的整个目录，即 `课间数据/course-tools/browser-extension`；目录中应含 `manifest.json`，不要选择单个文件。
5. 确认“课程主页 HAR 桥接”已启用，在同一个浏览器登录学校，保持学校标签打开，再到工具读取登录。
6. 如果工具打开的默认浏览器不是已登录的浏览器，请用“复制连接链接”，将链接粘贴到已登录且安装扩展的浏览器中。

从旧版迁移或移动程序目录后，扩展的路径会改变。请移除失效旧项，从当前位置重新加载。安装方式参照 [Edge 官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)、[Chrome 官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 同目录数据与迁移

默认数据根为 EXE 旁的“课间数据”：课表和提醒快照在根目录，应用浏览器配置在 `WebView2` / `QrWebView2`，工具及扩展在 `course-tools` 和 `runtime`，临时文件也留在此目录。请先将发布包解压到固定、可写的文件夹再运行；目录不可写时不会改用 AppData。

公开版不自动读取 AppData 中的旧版课表。首次在空目录运行时为空课表，已有同目录个人数据正常保留；可通过 JSON 手动导入本人课表。

移动或备份时请带上 EXE 和整个“课间数据”目录，单独复制 EXE 只会带走内置课表。分享程序时请分享干净发布包，不要附带使用后的个人数据目录。

课程工具源码位于 `desktop/course-tool`，与课表仅交换课程定位信息，不附带个人账号、Cookie、HAR 或报告文件。

开发：先在项目内安装固定版本 PyInstaller（`desktop/.packaging`），再运行 `npm run build:exe`。源码与模拟测试位于 `desktop/course-tool`；Python、Tk/Tcl 和打包器许可随发布目录的 `课程工具第三方许可.txt` 提供。打包器说明见 [PyInstaller 官方文档](https://pyinstaller.org/en/stable/usage.html)。
